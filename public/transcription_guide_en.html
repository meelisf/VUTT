Ligatures

  • æ, Æ, œ, Œ – transcribe using the specific character
  • ﬆ, ﬀ, ﬁ, ﬂ etc. – expand (st, ff, fi, fl)

Umlauts and Accents

  • ö, ä, ü, õ – always use modern forms
  • uͤ, oͤ, aͤ (letter + small e above) – transcribe as ü, ö, ä
  • å, Å (Swedish) – keep as is
  • Abbreviation mark (stroke over a letter; in print sometimes also wavy) – always a macron: ū, ō, ē, m̄, n̄, q̄, not a tilde (ũ, ñ, õ). Insert it with the ◌̄ button in the special characters panel or Alt+M (Mac: ⌥M) – the macron goes on the letter before the cursor; press again to remove. Estonian õ is a letter, not an abbreviation – it is not changed.
  • Accents – circumflex, acute, grave (â á à; Greek ᾶ ά ὰ) – with the ◌̂ ◌́ ◌̀ buttons in the same panel: the mark goes on the letter before the cursor; press again to remove; a new accent replaces the old one. If a Greek breathing (ἀ) is present, the accent goes after it (ἄ).

Special Characters

  • ſ (long s) – transcribe as ſ
  • ß (double s) – transcribe as ß

Abbreviations

  • que abbreviation (ꝗ etc.) – write as q;
  • -us abbreviation (ꝰ) – can be expanded

Formatting

Select the text and press the toolbar button (or shortcut). The same button on already formatted text removes the formatting; the Clean button removes all formatting from the selection.

  • Italic – I button (Ctrl+I). If the whole page is in italics, still mark all of the text as italic – do not skip it because italic is the “normal” type on that page.
  • Bold – B button (Ctrl+B). Early modern print practically never uses it – emphasis there is italic and change of typeface. Use it in later texts (e.g. 19th century) where bold type actually occurs.
  • Code-switching = a change of typeface – 𝔉 button (Ctrl+K); the marked text gets a grey background. Mark both a word set in Antiqua within Fraktur text (typically a Latin word in German text) and a word set in Fraktur within Antiqua text. Mark the typeface, not the language: a change of language within the same typeface is not marked. Antiqua italic within Antiqua text is italic, not code-switching.
  • Type size is not marked. Large type on a title page or in a heading stays unformatted – do not make it bold. Italic and change of typeface are still marked there as elsewhere.

Marginalia

  • Type the marginal note into the main text on its own line, above the main-text line next to which the note begins on the page. Each line of the note on the page is a separate line in the editor too.
  • Select the lines of the note and press Marginalia. The lines disappear from the main text and appear in the margin column beside it (on a narrow screen, as a small badge at the line).
  • With no selection, Marginalia creates an empty note above the cursor line that you can type into right away.
  • To correct a note, click it in the column – it opens in the text with a coloured background. Esc closes it.
  • Italic and other formatting inside a note use the same buttons as in the main text. With nothing selected and the cursor in an open note, the button formats the whole note.
NB! If in doubt, leave a note in the comments field (Info & Annotations → Comments).
